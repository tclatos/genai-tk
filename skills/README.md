# GenAI Toolkit Skill Map

This folder contains skills for agents working inside this repository or inside projects generated by `cli init`.

Two distinct skill sets live here — use the one matching your task:
- `skills/genai-tk/*` — **dev skills for working on genai-tk itself** (this repo). Referenced from this repo's own `AGENTS.md`.
- `skills/copilot/*` — **scaffolded into new consumer projects** by `cli init` to teach Copilot how to extend *those* projects (see [docs/design/copilot-agent-support.md](../docs/design/copilot-agent-support.md) and the "Skills reference" section below).

Use `skills/genai-tk/repo-map` first when you need orientation. Domain skills mirror `docs/` and point to the concrete code, config, and tests that implement each feature.
